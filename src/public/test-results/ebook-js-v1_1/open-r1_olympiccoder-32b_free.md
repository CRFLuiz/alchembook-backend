# Problem

Danik urgently needs rock and lever! Help him to find these magic words in a given string s.

A rock in string s is a non-empty substring of s, such that each letter of this substring is a "r", "o", "c" or "k".

A lever in string s is a non-empty substring of s, such that each letter of this substring is a "l", "e" or "v".

A substring of s is a sequence of consecutive letters of s.

Danik understands that it may be impossible to find a rock and a lever in string s, so he decided to remove some letters from the string s. Danik wants to remove as few letters as possible.

Execution time limit: 1.0 seconds
Memory limit: 256.0 MB

## Input Format
The only line of the input contains one string s (1 ≤ |s| ≤ 500) — the string Danik has.

## Output Format
In the first line print one integer k — the minimum number of letters Danik needs to remove from the string s to make it possible to find a rock and a lever in the resulting string.

In the second line print the string s with k letters removed in such a way that it contains at least one rock and at least one lever. If there are multiple answers, print any of them.

## Examples
```input
leetcode
```
```output
1
leetc
```
-----
```input
rvofukexyz
```
```output
0
rvofukexyz
```
-----
```input
rocklevers
```
```output
0
rocklevers
```
-----
```input
children
```
```output
4
ile
```

## Note
In the first sample Danik needs to remove one letters «o», so there are two «c» and two «e» left. Danik can use «leet» as a lever and «c» as a rock.

In the second and the third samples Danik doesn't need to remove any letters because "rvofuk" is a rock and "exyz" is a lever.

In the fourth sample Danik needs to remove letters «h», «n», «d» and «r», so only letters «ile» left. Danik can use «il» as a lever and «e» as a rock.
